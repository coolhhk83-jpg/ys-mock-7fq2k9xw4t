연세대 제시문 면접 현장녹화 모의시험

고사장 태블릿 화면을 재현: 테스트 녹화 → 지문 숙지 8분 → 자동 녹화 최대 5분(최소 2분) → 확인, 평가

응시 정보

이 브라우저는 음성 인식을 지원하지 않아 전사가 꺼집니다. Chrome 또는 Edge를 쓰세요.
카메라 녹화는 https:// 또는 파일을 직접 연 file:// 주소에서만 동작합니다.
이 브라우저는 MediaRecorder를 지원하지 않습니다. 최신 Chrome 또는 Edge에서 열어 주세요.

문제지 (선택)

진행 순서

1. 카메라, 마이크 확인
2. 카운트다운 3초 → 테스트 녹화 10초 (화면 문장을 읽음)
3. 카운트다운 3초 → 지문 숙지 8분 (종이 문제지 개봉, 구상지 작성)
4. 숙지 종료 시 별도 조작 없이 자동 녹화. 왼쪽 위에 남은 면접 시간과 최소 면접 시간 표시
5. 최소 시간 경과 후 왼쪽 아래 버튼으로 종료 가능. 시간 만료 시 자동 종료
6. 녹화 확인과 평가
